# Minimalist Editorial UI Skill

Use this skill whenever designing or updating web interfaces in this project to maintain a humanized, professional, gallery-grade aesthetic.

## Core Design Principles

1. **Zero Emoji & AI-Cliché Policy**:
   - Never use decorative emojis (`🌹`, `✨`, `💌`, `🔒`, `♥`, etc.) in UI labels, buttons, badges, or canvas particle systems.
   - Never use neon pink/purple gradients, glowing multi-layered text shadows, or tilted comic-style floating cards.

2. **Monochrome & Warm-Ivory Restraint**:
   - Primary surface: deep matte carbon (`#040405`), secondary elevated surface (`#0a0a0c`).
   - Primary typography: warm ivory (`#eceae6`), secondary slate (`#8e8d94`), muted index labels (`#525259`).
   - Borders: `1px solid rgba(255, 255, 255, 0.08)` hairline dividers.

3. **Typographic Hierarchy**:
   - Arabic display & literary quotes: `Amiri` (`font-weight: 400`, clean leading, zero neon glow).
   - Arabic UI & captions: `IBM Plex Sans Arabic` (`font-weight: 300–400`).
   - Index numbers & technical metadata: `JetBrains Mono` (`10px`, uppercase, `letter-spacing: 0.2em+`).

4. **Spatial Discipline & Unobstructed Canvas**:
   - Keep the central 3D ASCII artwork completely unobstructed.
   - Dock navigation and media archives along architectural rails (`left: 28px`) and a single hairline footer bar (`height: 46px`), using grayscale-to-color hover transitions (`filter: grayscale(100%)` to `grayscale(0%)`).
